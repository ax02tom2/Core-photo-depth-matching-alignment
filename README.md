# 岩心箱照片校正與成果輸出

**程式版本：2.11**

這是一套以 **Streamlit + OpenCV + Python** 製作的岩心箱照片校正工具，用來將現場拍攝的岩心箱照片轉向、偵測箱框四角、進行透視校正，並輸出成與既有成果格式接近的 **PDF / Word**。

> **重要：本程式目前沒有串接 AI 模型。**
> 自動判斷主要使用 OpenCV 的顏色遮罩、輪廓、直線／Hough 線段、幾何交點與透視轉換；自動結果仍建議由使用者逐張檢查。

---

## 1. 主要功能

### 1.1 多張岩心箱照片上傳

- 可一次上傳多張 JPG / JPEG / PNG。
- 依檔名中的數字自然排序，例如：
  - `H25-1B_1.jpg`
  - `H25-1B_2.jpg`
  - `H25-1B_10.jpg`
- 適合一次處理一個鑽孔的連續岩心箱照片。

### 1.2 照片方向校正

- 支援直式照片自動轉橫式。
- 可設定全部照片額外旋轉：`0 / 90 / 180 / 270`。
- 也可以對目前照片單獨設定額外旋轉。

### 1.3 自動偵測岩心箱四角

程式會優先利用岩心箱的藍色箱體特徵與幾何線索尋找箱框，主要包含：

1. HSV 藍色遮罩。
2. 藍色箱體的輪廓與線段分析。
3. Hough 線段群組。
4. 箱體外框與內緣直線擬合。
5. 相鄰直線求交點得到四個角。
6. 必要時使用舊方法作 fallback。

照片有歪斜時，程式不是單純旋轉，而是利用四角做透視校正，因此可以把傾斜拍攝的箱子拉正。

### 1.4 手動拖曳四角

左側原圖提供四個黃色角點，可直接拖曳到正確位置。

手動修正是「目前這一張照片」自己的設定，不會連帶修改其他照片。

常用操作：

- **恢復本張自動角點**：清除目前照片的手動角點，回到自動結果。
- **本張調整**：只調整目前照片的留邊。
- **重設本張裁切留邊**：把目前照片的留邊設定恢復為預設值。

### 1.5 每張照片獨立裁切／留邊

以下參數是以「本張照片」為單位保存，而不是全域共用：

- 左右留邊 `%`
- 上下留邊 `%`
- 角點向外留邊 `%`

目前介面預設值皆為 `0`，需要時再針對單張照片調整。

### 1.6 最後深度自動處理

程式會從「孔號」文字中尋找類似 `(50m)` 或 `（50m）` 的終深資訊。

目前固定規則：

- **每槽 = 1 m**
- **每箱 = 4 槽**

例如孔號：

```text
H25-1B(50m)
```

程式會自動把輸出限制在 `50m`，因此：

```text
1～48   → 正常滿箱
49～50  → 最後一箱只保留 2 槽
51～52  → 不輸出
```

最後一箱不會因為只剩 1～3 槽而重新拉成完整四槽高度；輸出時只裁掉終深以後的空槽。

如果孔號沒有寫終深，程式才會使用最後一張照片的槽位判斷作為備援。

### 1.7 PDF / Word 成果輸出

支援：

- PDF
- DOCX（Word）

成果版面包含：

- 告示牌／成果表頭
- 孔號
- 深度區間
- 日期
- 工程名稱
- 岩心箱成果圖
- 箱號
- 「鑽探結束」標記

表頭可以使用內建預設告示牌，也可以上傳自己的告示牌照片。

## 2. 操作流程

### 步驟 1：填寫成果表頭

在左側輸入：

- 工程名稱
- 孔號
- 日期
- 自訂告示牌照片（選填）

日期使用日曆選擇器。

### 步驟 2：上傳照片

一次上傳同一鑽孔的岩心箱照片。

建議依深度由淺到深命名，程式會進行自然排序。

### 步驟 3：確認方向

設定直式照片轉橫方向；必要時再針對個別照片使用額外旋轉。

### 步驟 4：檢查自動角點

畫面中：

- 左側：原始／已轉向照片 + 四個黃色角點。
- 右側：**「校正後（成果用）」**。

右側區塊就是最後放進 Word / PDF 的成果樣式，應以這一區作為最後確認依據。

### 步驟 5：必要時拖曳角點

如果黃色角點沒有準確落在箱子的內側四角，直接拖曳角點修正。

修正後右側成果預覽會同步更新。

### 步驟 6：調整本張留邊

若岩心太靠近裁切邊界，使用「本張調整」中的：

- 左右留邊
- 上下留邊
- 角點向外留邊

並觀察右側成果預覽。

### 步驟 7：逐張檢查

程式提供自動判斷狀態，但**不要只看「自動 OK」就直接輸出**。

建議至少確認：

- 四個黃色角點是否正確。
- 岩心是否被切到。
- 箱體是否被過度拉伸。
- 最後一箱是否只保留實際深度。
- 右側「校正後（成果用）」是否符合預期。

### 步驟 8：產生成果

確認全部照片後，按：

**產生 Word / PDF**

再下載成果檔。

## 6. 影像校正原理

本程式的核心不是單純「裁圖」，而是：

```text
原始照片
   ↓
EXIF 修正／方向統一
   ↓
OpenCV 找岩心箱藍色幾何線索
   ↓
取得箱框四角
   ↓
四角透視校正
   ↓
依「本張照片」的留邊設定調整
   ↓
必要時裁掉終深後的空槽
   ↓
成果圖
   ↓
PDF / Word
```

四角透視校正使用 OpenCV perspective transform，因此原始照片如果有拍攝角度偏差，可以把箱框重新拉成成果圖矩形。

## 7. 為什麼「右側成果預覽」最重要

自動偵測的目的只是幫使用者減少手動工作量，不代表自動結果一定正確。

尤其以下情況可能需要人工調整：

- 箱蓋、其他藍色箱體干擾。
- 箱壁被泥土、鞋子或工具遮住。
- 光線造成藍色變淡或反光。
- 箱體嚴重歪斜或部分超出照片。
- 岩心／標籤與箱壁顏色接近。
- 箱框內側線條不完整。

因此正式輸出前，建議以右側 **「校正後（成果用）」** 逐張確認。

## 8. 自動偵測失敗時的處理方式

如果某張照片無法取得可靠四角：

1. 保留目前照片。
2. 直接使用左側拖曳角點功能。
3. 把四個黃色角點移到箱子的實際內側四角。
4. 觀察右側成果預覽。
5. 必要時調整「本張調整」留邊。

自動偵測失敗不應該造成整個網站中斷；程式會把該張列為需要檢查／設定，讓使用者手動處理。

## 9. 常見問題

### Q1：為什麼成果圖看起來被拉伸？

透視校正本身會把四角映射到成果矩形，因此一定存在幾何變換。

真正不正常的情況通常是「四個來源角點抓錯」。

處理方式：直接拖曳四個黃色角點，直到左側箱框正確，再確認右側成果。

### Q2：49～50 為什麼只應該出兩槽？

因為目前規則固定為：

```text
1 槽 = 1 m
4 槽 = 1 箱
```

若孔號含 `(50m)`，輸出終點就是 50m，所以最後一箱只保留 49、50。

### Q3：孔號沒有 `(50m)` 怎麼辦？

沒有終深時，程式會退回使用最後一張照片的槽位判斷作為備援。

但如果是正式成果，建議在孔號中提供明確終深資訊。

### Q4：日期怎麼輸入？

使用左側日期欄位的日曆選擇器即可；輸出格式會轉成 `YYYY.MM.DD`。

### Q5：為什麼按「恢復本張自動角點」後畫面會重新整理？

這是 Streamlit 用來重建目前照片角點元件的正常行為。重整後會清除該張照片的手動角點設定。

### Q6：需要把 `__pycache__` 上傳嗎？

不需要。

## 10. 目前版本定位

**v2.11** 的主要定位是：

- 保留 OpenCV 自動箱框偵測。
- 提供可直接拖曳的人工角點修正。
- 每張照片獨立調整裁切留邊。
- 自動處理孔號中的終深。
- 支援半箱成果輸出。
- 強調「校正後（成果用）」作為最終檢查區域。
- 提供較清楚的照片切換與視覺化介面。

本版本**不是 AI 視覺辨識版本**。若後續要升級 AI，可將 AI 視覺模型放在「OpenCV 初始角點 → AI 二次確認／修正」這一層，而不必整個重做輸出與版面系統。

## 11. 維護建議

修改程式時建議保持以下原則：

1. `app.py` 負責 UI 與流程。
2. `core.py` 負責影像與輸出。
3. `point_editor/` 只負責前端拖曳角點。
4. 不要把 OpenCV 偵測邏輯全部塞進 `app.py`。
5. 重大版本更新時同步更新 `APP_VERSION` 與本 README。
6. 部署前先確認 `app.py`、`core.py`、`requirements.txt`、`point_editor/` 四者版本一致。
